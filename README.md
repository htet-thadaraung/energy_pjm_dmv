# The role of solar DERs in the PJM Interconnection

This research project will explore the role solar DERs can play in addressing energy usage and shortage issues within the PJM Interconnection in the DMV area.
The current outline of the repo is as follows:
* raw_data 
* processed_data
* analysis
* outputs 

Notes: The analysis is being done locally on VS Code and then pushed to GitHub.
